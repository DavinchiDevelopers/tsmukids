# 👨‍⚕️ TSMU Kids
TSMU Kids is a Next.js application built with TypeScript, utilizing Firebase for hosting and data management. It showcases a robust and scalable web application with a focus on performance, security, and maintainability. The project leverages the power of Next.js for server-side rendering, static site generation, and API routes, while Firebase provides a reliable and scalable infrastructure for hosting and data storage.

## 🚀 Features
- **Server-side rendering**: Next.js enables server-side rendering for improved SEO and faster page loads.
- **Static site generation**: Next.js generates static HTML files for pages, reducing the load on the server and improving performance.
- **API routes**: Next.js provides API routes for handling server-side logic and integrating with external services.
- **TypeScript support**: TypeScript ensures type safety and maintainability throughout the codebase.
- **Firebase hosting**: Firebase provides a scalable and reliable hosting solution for the application.
- **Firebase Firestore**: Firebase Firestore is used for data storage and management, providing a NoSQL database for flexible and scalable data modeling.

## 🛠️ Tech Stack
- **Next.js**: A popular React-based framework for building server-side rendered and statically generated websites and applications.
- **TypeScript**: A superset of JavaScript that adds optional static typing and other features for improving code maintainability and scalability.
- **Firebase**: A comprehensive platform for building web and mobile applications, providing hosting, data storage, and authentication services.
- **React**: A JavaScript library for building user interfaces and reusable UI components.
- **ESLint**: A static code analysis tool for identifying and reporting on potential errors and inconsistencies in JavaScript code.
- **Tailwind CSS**: A utility-first CSS framework for building custom and responsive user interfaces.

## 📦 Installation
To get started with the project, follow these steps:
1. Clone the repository using `git clone`.
2. Install the dependencies using `npm install` or `yarn install`.
3. Configure the Firebase settings by creating a `firebase.json` file and updating the `next.config.ts` file with your Firebase project details.
4. Start the development server using `npm run dev` or `yarn dev`.

## 💻 Usage
To run the application locally, follow these steps:
1. Start the development server using `npm run dev` or `yarn dev`.
2. Open a web browser and navigate to `http://localhost:3000`.
3. Interact with the application and explore its features.
